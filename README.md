# ⚡ POKÉVAULT — Ultra-Smooth Holographic Pokémon E-Commerce Platform

A futuristic, high-performance Pokémon card e-commerce web application featuring **interactive 3D holographic tilt physics**, **cinematic card showcase**, **virtual booster pack opening simulator**, **real-time market ticker**, and a **complete checkout experience** — engineered for **silky-smooth 60 FPS animations with zero lag**.

---

## 🌟 Key Features

### 🎴 1. 3D Holographic Card Physics Engine
* **Interactive Dynamic Tilt**: Cards track mouse position with hardware-accelerated 3D perspective transforms (`rotateX`, `rotateY`, `translateZ`).
* **Prismatic Holo Foil & Cosmic Glitter**: Dynamic rainbow diffraction grating and glint specular light sweeps that react in real-time to viewing angles.
* **PSA / BGS Graded Slab Mode**: Authentic acrylic slab encapsulation with Gem Mint 10 red labels, serial numbers, and subgrades (Centering, Edges, Corners, Surface).
* **360° Card Flip Inspector**: Inspect both the front artwork and the iconic reverse side of vintage and modern cards.

### 📦 2. Interactive Virtual Booster Pack Opening Simulator
* **Tear-To-Open Mechanic**: Click and rip open virtual foil booster packs with realistic audio feedback.
* **Surge Animation**: High-energy aura reveal with suspense delay and glowing card discovery.
* **Celebratory Confetti**: Multi-colored celebratory particle bursts powered by `canvas-confetti`.
* **Instant Claim**: Add your pack pulls directly into your Vault Cart!

### 📈 3. Live Collector Market Pulse Ticker
* Continuously scrolling real-time financial ticker tracking historical price changes and live auction bids for grails like *1999 1st Edition Charizard*, *Moonbreon*, and *Pikachu Illustrator*.

### 🛒 4. Full-Featured Collector Cart & Armored Checkout
* **Slide-Over Glassmorphism Cart**: Quantity toggles, real-time total calculation, and free shipping progress meter.
* **Promo Code Engine**: Test codes like `PIKACHU10` (10% off) or `CHARIZARD` (15% off).
* **Armored Security Checkout**: Multi-step checkout with simulated Titanium collector credit card and encrypted order confirmation.

### 🔊 5. Zero-Latency Web Audio API Synthesizer
* Native synthesizer sound engine generating crisp UI sounds (whoosh, holographic crystal chime, foil tear, coin collect, and fanfare) with zero external MP3 latency and a one-click mute toggle.

### ⚡ 6. Ultra-Smooth Performance (0% Lag Guarantee)
* **GPU Hardware Acceleration**: Uses `transform: translate3d` and `will-change: transform`.
* **Smart Particle Canvas**: Ambient ember and stardust particle background automatically throttled when not in view.
* **Performance Mode Toggle**: Switch between **60 FPS High-Speed** and **Ultra Cine FX** modes directly from the navbar.
